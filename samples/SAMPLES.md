# samples

这些文件只用于本地验收 `python app.py --self-test`，不参与 exe 打包，可以随时删除。`README.md` 本身也是 Markdown 查看器的样例。

- `验收文档.pdf/docx/odt/rtf`
- `销售数据.xlsx`、`产品演示.pptx`
- `sample.*`（PNG/JPEG/GIF/WEBP/TIFF/BMP/ICO/SVG）
- `示例图层.psd`、`示例矢量.ai`
- `测试音频.*`、`旋律.mid`、`演示视频.*`
- `素材归档.zip/7z`、`备份.tar.gz`
- `示例数据库.sqlite`、`城市点位.dbf`、`科学数据.h5`
- `演示模型.onnx`、`权重.pt`、`对象.pkl`
- `球体.stl/obj/glb`、`示例模型.step`、`示例图纸.dxf/dwg`
- `城市点位.shp/shx/prj`、`示例地图.kml`、`示例轨迹.gpx`
- `示例电子书.epub`、`示例邮件.eml`、`邮件归档.mbox`

字体样例未包含在仓库中，避免再分发商业字体；字体查看器在 Windows 上可直接打开系统字体。
